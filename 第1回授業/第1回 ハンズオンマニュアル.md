# 第1回 ハンズオン指示書「システム分解ワーク」

システム開発（基礎）第1回

## 課題の概要

| 項目 | 内容 |
| --- | --- |
| 課題 | 身近なシステムを1つ選び、4つの視点で分解してボードにまとめる |
| 形態 | グループ（G1〜G6） |
| 時間 | 作業30分＋発表7分 |
| 使うもの | FigJam ボード（Classroom「第1回」のリンク）の自分のグループのエリア |
| 提出物 | 完成したエリアのスクリーンショット（グループで1つ） |
| 期限 | 次回の授業開始まで |

## 目的

システムは「誰が使い、何を入れ、中で何をして、何を出すのか」で説明できます。この分解は、システム開発の最初の工程である**分析**（何を作るのかを明らかにする）の第一歩です。今日は、中身が分からない部分があることに気づくことが目的です。

## 完成の条件

次の4つをすべて満たしたら完成です。

1. 「1 システム名」の枠に、選んだ題材カードが置かれている
2. 「2 登場人物」「3 入力」「4 処理」「5 出力」「6 なかったら困ること」の各枠に、付箋が **2枚以上** ある
3. グループ全体で付箋が **（人数×5）枚以上** ある（重複をまとめる前の数）
4. 「4 処理」の付箋の1枚に **★** が付いている（グループで一番自信がないもの）

## 作業の指示

**① 題材を決める（5分）** 左側の題材カード6枚から1枚を選び、「1 システム名」の枠に移動しなさい。迷ったら、メンバーが一番よく使っているものを選びます。

**② 一人で書き出す（10分）** 話し合わずに、各自で付箋を貼りなさい。1人5枚以上、付箋1枚に1つのことだけを書きます。付箋の色は枠の説明に合わせます（登場人物・なかったら困ること＝黄、入力・出力＝緑、処理＝ピンク）。

**③ グループで整理する（7分）** 同じ内容の付箋は1枚にまとめ、違う枠に貼られた付箋は正しい枠へ移しなさい。

**④ ★を付け、発表者を決める（5分）** 「4 処理」のうち、本当はどうなっているのか一番自信がない付箋に★を付けなさい。発表者を1人決めます。

**⑤ 発表する（指名されたグループのみ、約3分）** 次の3点を話しなさい。

- 選んだシステムと、その登場人物
- 入力 → 処理 → 出力 の流れ
- ★を付けた処理と、自信がない理由

## ヒント

- 普段の使い方だけでなく「うまくいかないとき」も考える（題材カードの問いを使う）
- 使う人だけでなく、裏で管理する人の立場も考える
- 処理は「〜を確認する」「〜を計算する」「〜を記録する」のように動詞で書く
- 処理は想像でかまわない。正解はない

ボード左下の「記入例：自動販売機」も参考にしなさい。


操作が分からないときや、ボードが開けないときは、手を挙げて先生を呼ぶこと。
