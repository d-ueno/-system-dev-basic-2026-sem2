# 授業パッケージの使い方（全15回）

## フォルダ構成
- 00_共通 … 本書・テキスト対応表・運用ルール
- 01〜15 … 各回のフォルダ。中身は以下の命名規則
  - 00_授業進行表.md … 90分の分単位進行（講師/受講者の動き・投影物）
  - 01_トークスクリプト.md … 講義パートの講師用原稿（スライド指示入り）
  - 02〜_配布_*.md / *.csv / *.py … 配布資料の原稿（CSVはスプレッドシートに取込む）
  - 0X_小テスト.md … 前回範囲の確認テスト5問＋解答（Googleフォーム化して使用）
  - 90_講師用_*.md … 模範解答・仕込みの種明かし・評価基準（受講者非公開）

## 運用ルール（要点）
1. テンプレは閲覧専用で配布し、受講者が各自コピーして使用（原本保護）
2. ファイル名規則：`第n回_成果物名_氏名`（グループ物は `_G番号`）
3. ID体系は全編共通：要求No → 機能ID(F-xx) → 画面ID(S-xx)/帳票ID(R-xx) → シナリオID(SC-xx)
4. CSV原稿はGoogleスプレッドシートにインポート後、指定のプルダウン・条件付き書式を設定
5. テキスト（ISBN978-4-7981-5756-6）の紙面コピーは配布しない。参照はページ番号指示で行う
6. 通信障害に備え、全配布資料のPDF版を印刷可能な状態で保持しておく

## 標準タイム配分（各回共通の骨格）
0:00-0:10 小テスト＋前回振り返り／0:10-0:40 講義／0:40-1:20 ハンズオン／1:20-1:30 共有・まとめ・宿題提示

## ファイル名について（文字化け対策）
ZIP展開時の文字化けを避けるため、フォルダ・ファイル名はすべて半角英数字にしています（内容は日本語）。
- 00_lesson_flow = 授業進行表 ／ 01_talk_script = トークスクリプト ／ handout_ = 配布資料 ／ quiz = 小テスト ／ teacher_ = 講師用（非公開）
- 全ファイルの対応表：00_common/filename_mapping.csv（Excelでそのまま開けます）
