# 【第09回】01_トークスクリプト

## 第9回 トークスクリプト（講義15分）

### ①製造工程：設計書がコードになる（7分）
「設計書一式が揃い、いよいよ製造——プログラミングです。この授業はプログラミングの授業ではないので、書く訓練はしません。その代わり、現場で新人が最初に任される仕事をやります。**コードレビュー**——他人のコードを読んで問題を指摘する仕事です。」
「まず前提を1つ。製造のインプットは内部設計書です。プログラマの創作ではなく、設計の翻訳。先週『この文書だけで作れるか』とレビューした理由がここで効いてきます。」

### ②動くコード≠良いコード（8分）
「今日一番持ち帰ってほしい言葉はこれです。**『動く』と『良い』は別物**。この後お見せするコードは、実行するとちゃんと正しい答えを出します。でもひどいコードです。なぜひどいのか？——半年後に読む人（未来の自分を含む）が理解できない。直せない。それは組織にとって借金です。」
「だから現場には**コーディング規約**があります。名前の付け方、コメント、書式。配った10条を見てください。1つだけ解説すると、第5条マジックナンバー禁止。コードの中に裸で『500』と書いてあったら、それは送料？税額？意味が分からない数字＝マジックナンバー。名前を付けて `SHIPPING_FEE = 500` と書けば意味が通る。」
「レビューの作法：**行番号＋条番号＋修正案**をセットで指摘する。『なんか汚い』は指摘ではありません。では、汚いけど動くコードをまず実行して見せます。」

# 【第09回】05_配布_refactored_code（配布資料）

## リファクタリング後（答え合わせ後に公開。同一入力で同一結果になることをColabで確認させる）
MIN_QUANTITY = 1
MAX_QUANTITY = 10
TAX_RATE = 1.08  # 消費税8%（軽減税率対象を想定）

def is_valid_quantity(quantity):
    """数量が許容範囲(1〜10)かを判定する。"""
    return MIN_QUANTITY <= quantity <= MAX_QUANTITY

def calc_total_with_tax(order_items):
    """注文明細 [(単価, 数量), ...] から税込合計を計算する。
    数量が不正な明細があれば ValueError を送出する。"""
    subtotal = 0
    for unit_price, quantity in order_items:
        if not is_valid_quantity(quantity):
            raise ValueError(f"数量が不正です: {quantity}（{MIN_QUANTITY}〜{MAX_QUANTITY}）")
        subtotal += unit_price * quantity
    return int(subtotal * TAX_RATE)

def print_total(total_yen):
    """合計金額を表示する。"""
    print(f"合計は {total_yen} 円です。")

## 動作確認
total = calc_total_with_tax([(400, 2), (450, 1)])
print_total(total)
