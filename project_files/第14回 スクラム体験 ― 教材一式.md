# 【第14回】01_トークスクリプト

## 第14回 トークスクリプト（講義17分）

### ①スクラム：アジャイルの代表的なやり方（10分）
（スライド：スプリントの輪）
「今日は座学を最小にして、アジャイルの代表的な進め方**スクラム**を体で覚えます。核は**スプリント**——1〜4週間の固定周期。今日は10分に短縮してこれを2周します。」
「1周の中身は4つ。**スプリント計画**：バックログ（やることリスト）から今回やる分を選ぶ。**スプリント**：作る。**スプリントレビュー**：動くものを見せて受け入れ判定。**ふりかえり**：やり方自体を改善する。注意——レビューは『成果物』の検査、ふりかえりは『進め方』の検査。別物です。」
「役割は3つ。**プロダクトオーナー（PO）**：何を作るか・順番を決める人。受入判定もPOの仕事。**スクラムマスター（SM）**：進め方の番人。時間を守らせ、妨害を取り除く。偉い人ではなく世話役。**開発チーム**：作る人。今日は全グループでこの3役を回します。」

### ②2つのルールが体験の肝（7分）
「今日、絶対に守ってもらうルールが2つ。1つ目、**タイムボックス**。時間が来たら未完成でも止める。延長なし。『あと1分』もなし。時間を固定するから、見積もりと優先順位が磨かれるんです。2つ目、**Doneの定義**。『できた』を宣言できる条件を先に決める。今日は『Figmaの再生モードで、ストーリーを最初から最後まで操作できること』。半分できたは、できていない。」
「やることは学食アプリの動くプロトタイプ。要求は**ユーザーストーリー**の形で書きます。『学生として、当日メニューが見たい。なぜなら行く前に売切れを知りたいから』——利用者の言葉で、理由まで書く。仕様書の代わりに、このカードと会話で進めるのがスクラム流です。……それから、予告なしの出来事が起きるかもしれません。現実のプロジェクトと同じように。」（要求変更カードのこと）

# 【第14回】02_配布_ロールカード（配布資料）

## ロールカード（3種）
### プロダクトオーナー（PO）
やること：ストーリーの優先順位を決める／レビューでDone定義に照らして受入判定／質問に即答する（仕様はあなたが決める）
やらないこと：作業を手伝う／判定を曖昧にする（Done/未Doneを明言）

### スクラムマスター（SM）
やること：タイムボックスの番人（残り時間を声かけ）／詰まりの解消（ツール不調は講師へ）／ふりかえりの進行
やらないこと：内容への口出し／延長の許可（絶対にしない）

### 開発チーム
やること：計画で「今回やれる量」を自分たちで決める／Figmaで作る／レビューでデモする
やらないこと：POに無断でストーリーを差し替える

# 【第14回】03_配布_Trelloセットアップ（配布資料）

## Trelloボード構成（講師が原本作成→6G複製・招待）
リスト：①プロダクトバックログ ②スプリントバックログ(ToDo) ③Doing ④Done
カードテンプレ（説明欄に印字）：「〈誰〉として〈何〉がしたい。なぜなら〈理由〉」／ラベル：見積もりS(緑)/M(黄)/L(赤)
配置済みの例カード：「学生として当日メニューが見たい。なぜなら行く前に売り切れを知りたいから」(S)

### Done の定義（ボード上部に固定表示）
Figmaの再生モードで、そのストーリーを最初から最後まで操作できること

# 【第14回】05_配布_KPTシート（配布資料）

## KPTシート（FigJamボード原稿・2周分の枠）
| Keep（良かった・続ける） | Problem（困った） | Try（次スプリントで試す） |
記入のコツ：進め方について書く（成果物の出来はレビューで扱済み）。例：K「先に画面の枚数を決めたのが効いた」P「役割分担が曖昧で手待ちが出た」T「計画時に担当を決める」

# 【第14回】90_講師用_要求変更カード（講師用（非公開））

## 講師用：スプリント間に投入する要求変更カード（Trelloに講師が直接追加）
文言：「【A社より緊急】アレルギー事故が近隣校で発生。**メニューへのアレルゲン表示**を最優先で追加してほしい。学生として注文前にアレルゲンを確認したい。なぜなら安全に食べたいから」（見積もりM）

### 演出と観察ポイント
- 投入時は口頭でも「今、A社から連絡が入りました」とアナウンス（現実感を出す）
- 観察：POが優先順位を並べ替えるか／開発が抱えている作業を捨てられるか／文句を言いつつ対応する空気（=WFなら変更管理委員会モノ、アジャイルなら日常、という締めの解説に使う）
- 締めトーク：「今の『えー』という声、あれがWFで変更が高くつく理由の正体です。アジャイルはあの『えー』を仕組みで飲み込む型なんです」
